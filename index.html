Michael Mathews Game Dev Portfolio

Unity3D • C++ • C# • Java • Python

Procedural Dungeon Generator

A fully procedural dungeon generator built in Unity3D with C#. It creates randomized floorplans, intelligently connects rooms and corridors, and adapts layouts dynamically based on player or world parameters. Designed for repeatable, high‑variety level generation with clean, readable structure.

2D Multiplayer Client/Server

A custom 2D multiplayer engine built in Java using Swing, paired with a server I developed and deployed on DigitalOcean. Supports simultaneous connections from dozens of clients, real‑time movement, synchronized animation, and smooth state replication across the network.

MiniMX iOS Game

A Unity3D iOS title released on the App Store in 2025. Features a complete UI system, multiple level packs, a star‑based progression loop, and a cross‑platform save architecture. Designed for responsive touch controls and polished mobile gameplay.

Steam Integration

Demonstrates my ability to interface with the Steam API. This example pulls my Steam username, but the same integration supports fetching friends lists, triggering Steam actions, and working with authenticated connections. Built in Unity with C#.

C++ HTML Server

A lightweight HTTP server written in C++ capable of hosting static website files. Demonstration includes serving HTML forms locally, with support for deployment beyond the local environment. Built to explore low‑level networking, request handling, and server architecture.

2D Physics Engine Java

A small physics‑engine sandbox I built in Java using AWT and Swing. Boxes fall under gravity, pick up speed, collide, and stack on each other. I made it to understand the core ideas behind how physics engines work, motion updates, collision checks, and basic stacking behavior, without relying on any external libraries.

Custom FPS Controller

A first‑person controller built from scratch in Unity3D, including physics‑based movement, camera handling, and shooting mechanics. All environment and weapon models were created in Blender. Developed as a modular foundation for future FPS prototypes..

Voxel Zombie Shooter

Project built for a game-jam. Zombies explode into physics based voxels, voxels expire after 3 seconds, zombies AI tracks and moves towards player.

Python Tic-Tac-Toe

A text‑based tic‑tac‑toe game built in Python with full board rendering, input validation, and win/loss detection. Designed as a clean, minimal example of turn‑based logic and state management.
